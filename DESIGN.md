# Portfolio design direction

Reading this as a developer portfolio for recruiters and prospective clients, using a retro editorial visual language with ENERGY 3, RHYTHM 3, and MOTION 3.

## Major decisions

- Color: warm paper, charcoal, mustard, and terracotta create a print inspired identity while preserving strong contrast in both themes.
- Layout: asymmetric editorial compositions separate the featured case study from supporting work and make project priority immediately visible.
- Typography: Space Grotesk stays because its geometric shapes support the existing retro editorial character while remaining readable for technical content.
- Spacing: generous section gaps create reading pauses, while compact metadata keeps project evidence easy to scan.
- Cards: cards are reserved for portfolio artifacts that need a clear boundary, not used as the default container for every section.
- Paper grid: the subtle grid is kept only inside poster and project archive surfaces as an identity motif, never as a page wide technical background.
- Motion: entrance choreography guides attention, section reveals show reading progress, and interaction feedback confirms user actions. No decorative motion runs forever.
- Interactive filters: project filters let recruiters narrow the work by project context without navigating away from the page.
- Pointer response: the hero poster responds lightly to direct pointer movement to make the main identity object feel tactile, while touch and reduced motion users receive a stable layout.

- GitHub history: recent public events provide verifiable evidence of ongoing work, with honest loading, empty, and error states.
- System blueprint: the schematic decorates the page by explaining the relationship between application layers, so the visual also communicates technical thinking.
